### Go (Golang)

- [A Tour of Go](https://go.dev/tour/) — Official interactive introduction to Go syntax, data structures, and concurrency.
- [Go by Example](https://gobyexample.com/) — Hands-on, concise Go examples covering real-world concepts from structs to JSON.
- [Learn Go in Y Minutes](https://learnxinyminutes.com/docs/go/) — Quick visual cheat sheet for developers who want a fast syntax refresher.

### Docker & Containers

- [Docker 101 Tutorial](https://www.docker.com/101-tutorial/) — Learn how containers package code and dependencies for reliable execution.
- [Docker Documentation: Orientation and Setup](https://docs.docker.com/get-started/) — Official step-by-step introduction to images and containers.

### Web Basics & Scraping

- [MDN Web Docs: HTML & DOM Basics](https://developer.mozilla.org/en-US/docs/Learn/HTML) — Learn how web pages are structured with elements, tags, and attributes.
- [MDN Web Docs: CSS Selectors](https://developer.mozilla.org/en-US/docs/Learn/CSS/Building_blocks/Selectors) — Understand class, ID, and attribute selectors used to find page elements.
- [ChromeDP Documentation & Examples](https://github.com/chromedp/examples) — Examples for browser automation and scraping dynamic JavaScript pages in Go.

### Command Line & Shell

- [Bash / CLI Crash Course](https://developer.mozilla.org/en-US/docs/Learn/Tools_and_testing/Understanding_client-side_tools/Command_line) — Beginner-friendly guide to navigating files, running scripts, and managing processes in the terminal.
